# HRMS Codex Starter Kit

1. افتح مجلد المشروع في VS Code مع Codex.
2. انسخ `CODEX_PROMPT.md` داخل محادثة Codex (أو اطلب منه قراءة الملف كاملًا وتنفيذه).
3. صور المرجع داخل `references/`:
   - `01_employee_portal_reference.png`: الصورة الأولى (بوابة الموظف).
   - `02_admin_dashboard_reference.png`: لوحة إدارة الموارد البشرية.
4. نفّذ تطبيق Frontend تفاعليًا. المطلوب ليس نظامًا إنتاجيًا ولا استضافة.

مصادر تصميم إضافية في نص البرومبت. لا تنسَ مراجعة ترخيص أي كود خارجي قبل إعادة استعماله.
