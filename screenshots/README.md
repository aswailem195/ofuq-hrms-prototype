# لقطات العرض النهائية

- admin-dashboard.png: لوحة الإدارة، 1440×900.
- admin-dashboard-full.png: لوحة الإدارة كاملة مع الموافقات والموظفين والأنشطة.
- employee-portal.png: بوابة الموظف، 1440×900.
- employee-portal-full.png: البوابة كاملة مع الخدمات والمستجدات والتقييم.
- commissions.png: صفحة العمولات كاملة مع المرشحات والرسم والعمليات.
- payslip.png: نافذة كشف راتب نوفمبر 2026.
- tablet-portal.png: بوابة الموظف على 1024×768.
- mobile-portal.png: بوابة الموظف على 390×844.
- mobile-portal-full.png: كامل تجربة الهاتف.

التقطت الصور من النسخة المبنية باستخدام سكربت scripts/capture-screenshots.mjs، بعد تحميل الخط والصور المحلية. التقرير capture-report.json يثبت عدم وجود أخطاء أو صور مكسورة أو تجاوز أفقي على الهاتف. ملف PDF المعاين موجود في output/pdf/payslip-sample.pdf.
